# ContextTrail Active Docs

ContextTrail is now focused on document-heavy operational work: insurance,
finance, HR, sales, legal, compliance, banking, and other workflows where
agents need exact evidence from too many documents.

The old code-context planning surface has been archived at
`docs/archive/code-context-era-2026-05/`.

## Active Docs

- [CONTEXT.md](CONTEXT.md) defines the current product language.
- [PRODUCT_PLAN.md](PRODUCT_PLAN.md) describes the focused product direction.
- [ENGINE.md](ENGINE.md) maps the engine we have today.
- [EVAL_PLAN.md](EVAL_PLAN.md) defines how we measure real document workflows.
- [ROADMAP.md](ROADMAP.md) orders the next slices.

## Current Rule

New planning should update these active docs first. Only reach into the archive
for historical evidence, old decisions, or implementation archaeology.
