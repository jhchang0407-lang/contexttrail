# Code Context Era Archive

This folder contains the historical ContextTrail documentation from the
code-context and setup-engine phase of the project.

It is archived for reference, not deleted. New planning should start from the
active docs in `docs/`.

Notable contents:

- `prd/`: old PRD sequence.
- `adr/`: old architectural decision records.
- `evals/`: old retrieval and code-lane reports.
- `plan/`: old session plans and ranking experiments.
- `pilot/`: pilot notes from the setup/context engine phase.
- `previous-archive/`: files that were already archived before this reset.
